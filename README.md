# Claude Threads Kanban

Неофициальное расширение Chrome (Manifest V3), которое показывает треды проекта на claude.ai
(`claude.ai/code/project/chan_…`) в виде Kanban-доски: «Открытые», «В работе», «Зарезолвленные».

Все данные остаются в браузере (`chrome.storage.local`). Расширение ничего не отправляет на сторонние
серверы: оно только читает ответы, которые claude.ai и так загружает, и повторяет запросы самого
claude.ai от имени вашей сессии.

## Установка (dev)

```bash
npm install
npm run build        # или npm run watch
```

Chrome → `chrome://extensions` → включить «Режим разработчика» → «Загрузить распакованное» → папка `dist/`.

## Как пользоваться

* На странице проекта справа внизу появляется кнопка **▦ Kanban** (или `Alt+K`). `Esc` закрывает доску.
* Клик по карточке открывает тред в этой же вкладке (Ctrl/Cmd+клик — в новой).
* Карточки перетаскиваются между колонками и внутри колонки; порядок и колонки сохраняются по проектам.
* Переход в другой проект подхватывается без перезагрузки страницы.
* В DevTools Console видно, что нашло расширение: `[Claude Kanban] … thread(s) in project …` с таблицей тредов,
  какие JSON-ответы содержали треды и какие запросы похожи на «резолв».

### Синхронизация резолва

Эндпоинт резолва не зашит в код. Расширение **учится** ему: один раз зарезолвьте любой тред в обычном
интерфейсе Claude — расширение увидит запрос, запомнит его как шаблон (подставив `{{threadId}}`/`{{projectId}}`)
и дальше будет повторять его при перетаскивании карточки в «Зарезолвленные» (и обратный — при вытаскивании оттуда).
Заголовки `Authorization`, cookie, токены и т.п. не сохраняются — запрос идёт с куками вашей сессии.
Пока шаблон не выучен, перенос в «Зарезолвленные» сохраняется только локально.

Правила колонок: нативный резолв всегда главнее — зарезолвленный в Claude тред попадает в «Зарезолвленные»,
переоткрытый в Claude возвращается в «Открытые». «Открытые» и «В работе» — локальные.

## Как устроено

| Файл | Что делает |
| --- | --- |
| `src/shared/claude-endpoints.ts` | **Все** предположения о claude.ai: URL, формат id, имена полей JSON, селекторы DOM, правила распознавания резолва. Чинить поломки — здесь. |
| `src/page/hook.ts` | Скрипт в мире страницы: оборачивает `fetch`/`XHR`, пересылает JSON с тредами и запросы-кандидаты «резолва», выполняет повтор запросов. |
| `src/shared/extract.ts` | Эвристика: ищет в любом JSON объекты, похожие на треды; обучение шаблону резолва. |
| `src/shared/board-state.ts` | Логика колонок и порядка карточек (покрыта тестами). |
| `src/content/*` | Контент-скрипт: маршрутизация по проектам, DOM-фолбэк, хранилище, синхронизация. |
| `src/board/*` | UI доски в Shadow DOM. |

## Ограничения

* Неофициально: при изменении вёрстки или внутренних API claude.ai может сломаться (см. `docs/RESEARCH.md`).
* Только браузер, не десктопное/мобильное приложение.
