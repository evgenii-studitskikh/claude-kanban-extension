# Screenshot plan

The store needs 1 to 5 screenshots, **1280×800** (preferred) or 640×400, PNG or JPEG, no alpha.
Take them in a clean Chrome window on a real claude.ai project.

## Before you shoot

- Use a demo project with harmless thread titles (no private work, no names, no emails).
- Hide other extensions' toolbar icons and bookmarks bar.
- Set the window to exactly 1280×800: DevTools → Device Toolbar → Responsive 1280×800 → "Capture screenshot",
  or resize the window and use a screenshot tool, then crop.
- Light theme for all shots, so they look consistent.

## Shots

1. **The board** (hero). Board open over a project with ~8–10 cards spread across Open / In progress / Resolved.
   Caption idea: "All your project threads on one board".
2. **Drag and drop.** A card mid-drag between columns (or before/after pair edited into one image).
   Caption: "Drag cards to organize your work".
3. **Entry point.** The project page with the ▦ Kanban button visible in the bottom-right corner.
   Caption: "One click or Alt+K on any project page".
4. **Resolve sync.** A card moved to Resolved and the same thread showing as resolved in Claude's list.
   Caption: "Resolving a card resolves the thread in Claude".
5. *(Optional)* **Privacy.** A simple slide with the icon and "All data stays in your browser. No tracking."

Save the final images as `store/screenshots/01-board.png`, `02-drag.png`, and so on.
